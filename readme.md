# Flyout Menus

Right-click menus in Zen roll out like Windows 11 flyouts. A [Sine](https://github.com/CosmoCreeper/Sine) mod. I wanted those menus to follow WinUI's guidelines so I built it.

### Prerequisites

- Windows 11
- Zen Browser with Sine installed

## Install

1. Open Sine's mod marketplace in Zen settings.
2. Paste `artistro08/zen-flyout-menus` into the install box.
3. Restart Zen.
